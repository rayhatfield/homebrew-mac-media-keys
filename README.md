# homebrew-mac-media-keys

Homebrew tap for [Mac Media Keys](https://github.com/rayhatfield/mac-media-keys), a macOS menu bar app
that forwards media keys to a media app of your choice.

## Install

```bash
brew tap rayhatfield/mac-media-keys
brew install --cask mac-media-keys
```

## Update

```bash
brew upgrade --cask mac-media-keys
```
